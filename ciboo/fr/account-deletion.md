# Procédure de suppression de compte et de données - Ciboo

Cette documentation explique comment demander la suppression de votre compte et des données personnelles associées pour l'application **Ciboo**, développée par **Intelligence Industrielle**.

## 1. Comment demander la suppression de votre compte

Vous disposez de deux options pour supprimer votre compte et les données associées :

### Option A : Depuis l'application (Recommandé)
Le moyen le plus rapide de supprimer votre compte est d'utiliser la fonctionnalité intégrée à l'application :
1.  Ouvrez l'application **Ciboo**.
2.  Accédez à l'écran des **Paramètres** (icône d'engrenage).
3.  Sélectionnez votre **Profil** ou les options de compte.
4.  Appuyez sur **Supprimer mon compte**.
5.  Confirmez votre choix dans la boîte de dialogue de sécurité.

Une fois confirmé, votre compte est immédiatement désactivé et vos données sont mises en file d'attente pour suppression définitive.

### Option B : Demande par courriel
Si vous avez désinstallé l'application ou n'y avez plus accès, vous pouvez demander la suppression par courriel :
*   **Destinataire** : [support@intelligenceindustrielle.com]
*   **Objet** : Demande de suppression de compte Ciboo
*   **Message** : Veuillez indiquer l'adresse courriel associée à votre compte pour que nous puissions procéder à l'identification et à la suppression.

## 2. Types de données supprimées ou conservées

### Données supprimées
Lors de la suppression de votre compte, nous procédons à l'effacement définitif de :
*   **Profil utilisateur** : Nom, prénom, adresse courriel et photo de profil.
*   **Données d'activité** : Listes de courses, inventaires de produits et préférences personnalisées.

### Données conservées
Pour des raisons de conformité légale et de sécurité, nous conservons certaines informations :
*   **Historique de facturation** : Si vous avez un abonnement actif ou passé, les factures et reçus sont conservés pendant **7 ans** conformément aux lois fiscales applicables.
*   **Données de sécurité anonymisées** : Des logs d'accès anonymes peuvent être conservés temporairement (maximum 180 jours) pour prévenir les abus et assurer la sécurité du système.
*   **Données statistiques** : Les statistiques d'utilisation agrégées et anonymisées (ne permettant pas de vous identifier) sont conservées pour l'amélioration du service.

## 3. Durée de conservation supplémentaire
Pour les demandes effectuées via l'application, la suppression logique est immédiate. La suppression physique de toutes les sauvegardes peut prendre jusqu'à **30 jours**.
